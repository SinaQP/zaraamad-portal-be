# AGENTS Guide

## Mandatory Read Order

1. Read applicable rules under `agent-rules/`.
2. Read the related mini-doc in `docs/agent-mini-docs/` before editing code.

## Mini-doc Sync Rule

- Every code change must update the related mini-doc in `docs/agent-mini-docs/`.
- If no mini-doc exists for the touched area, create one in `docs/agent-mini-docs/` in the same change.
- Do not leave implementation and mini-docs out of sync.
